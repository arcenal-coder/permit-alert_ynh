1. Ouvrez Permit Alert et importez un premier PDF E-Permit.
2. Vérifiez les champs avant de valider : aucun permis n'est enregistré sans cette action.
3. Enregistrez le délai et la fréquence dans Réglages pour activer les rappels.
4. Ajoutez les destinataires et faites confirmer leurs adresses.

5. Configurez les connexions dans **Connecteurs**, enregistrez puis utilisez les diagnostics.

Pour la relève de `epermit@onyx-ingenierie.com`, renseignez sur place les
identifiants de la boîte dédiée. Les diagnostics ne traitent aucun message.
